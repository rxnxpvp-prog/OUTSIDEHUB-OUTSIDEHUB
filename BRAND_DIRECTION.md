# OutsideHub Brand Direction

OutsideHub should feel like a private digital network, not a SaaS dashboard.

## Core Feeling

- Secret digital infrastructure.
- Off-grid crews, operators, nodes, channels, drops, intel, operations and encrypted relays.
- Black and white, liquid glass, cold white glow, restrained contrast.
- Minimal copy. The interface should imply a system running instead of explaining features.

## Visual Ritual

- Terminal boot language.
- Signal pulse.
- Subtle status dots.
- Slow particles.
- Scanlines that are almost invisible.
- Procedural grain/noise.
- Huge soft shadows.
- Cinematic blur.
- Depth layers.
- Hover should feel magnetic, light and physical.

## Copy Rules

Prefer:

- NETWORK STATUS
- ACTIVE OPERATORS
- LIVE NODES
- CONNECTED CREWS
- Broadcast to network...
- Send encrypted signal...
- Drop intel...
- Share operation...
- Transmit update...
- Open channel...
- OPEN GATE
- ACCESS TERMINAL
- PRIVATE NODE

Avoid:

- productivity
- workspace
- platform
- dashboard
- solution
- generic marketing explanations

## Feed Direction

The feed is a private network channel.

Use small operational status above the feed:

- 27 operators online
- 4 active channels
- Encrypted relay stable

Posts are network transmissions or drops, not generic social posts.

## Member Direction

Members are operators/nodes.

Status examples:

- online
- idle
- encrypted
- ghost mode

Keep status dots extremely subtle.
